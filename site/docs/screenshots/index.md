# 界面预览

下面两张图由 [项目内置的 HTML 模板](https://github.com/asionbo/ohmic/tree/main/assets) 直接渲染，展示的是当前界面本身。二维码与链接中的令牌是示例值，不可用于配对；状态与输入文字为演示内容。

## 电脑端：扫码配对页

启动 ohmic 后，电脑浏览器会自动打开这个页面。用手机相机扫描二维码，即可进入输入页。

![电脑端二维码配对页](/images/pair-page.webp)

页面同时显示可复制的手机链接，以及同一 Wi-Fi、防火墙、网卡选择等排查提示。

## 手机端：文字输入页

在手机上打字，或使用系统键盘自带的麦克风进行语音听写，然后点「发送到电脑」。

![手机端文字输入页](/images/mobile-page.webp)

左上角绿点表示已连接。只有收到桌面端的确认回复后，输入框才会清空；断线重连时会自动重发尚未确认的内容，避免打字丢失。

::: tip 想看完整大小？
点击图片或在新标签页打开 `/images/pair-page.webp`、`/images/mobile-page.webp`。两页都支持系统的浅色 / 深色模式。
:::
